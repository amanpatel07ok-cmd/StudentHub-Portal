## Practical 1: Project Initiation, Requirement Analysis, Sitemap, and Initial Setup

### Project Overview
StudentHub is an academic management and campus portal designed for students and faculty of DEPSTAR, CHARUSAT. The portal centralizes course syllabi, attendance records, exam results, class schedules, and event registration into a seamless web portal.

### User Roles
- **Student:** Can access student dashboard, view profile, enrolled courses, syllabus, class timetable, attendance status, examination results, and register for university events.
- **Admin / Faculty:** Can access administrator dashboard, view statistical summaries, perform CRUD operations on student records, manage campus events, upload event posters, and view audit history.

### Required Minimum 10+ Pages
1. index.html - Main portal welcome landing page
2. choose.html - Role selector (Student / Administrator)
3. student_auth.html - Student authentication option gateway
4. student-login.html - Student login form
5. student-signup.html - Student account registration form
6. student-dashboard.html - Academic quick access dashboard
7. student-courses.html - Enrolled courses and credit breakdown
8. student-assignments.html - Pending and submitted coursework
9. student-attendance.html - Subject-wise class attendance tracking
10. student-result.html - Semester exam marks, SPI and CPI
11. student-timetable.html - Weekly lecture and lab schedule
12. student-profile.html - Student personal and academic profile
13. dmin-login.html - Administrator sign-in portal
14. dmin-dashboard.html - Administrator dashboard
